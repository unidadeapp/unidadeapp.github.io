Caixa de Feedback

Página só do Pedro, para ler o feedback que alguém gerou no app (botão "Gerar link para o Pedro") sem precisar de e-mail. O link em si já guarda o texto (depois do #, que nunca é enviado para nenhum servidor); esta senha só evita que alguém que ache o endereço leia por acaso.

Isto não é uma senha de verdade (é só um código no próprio arquivo da página, qualquer um que souber ler conseguiria passar). Não é diferente de quem já tem o link conseguir ler o texto: só não aparece sem digitar o código.
